# React.js Basics & Projects

Core React.js concepts and hands-on projects built while learning from [Hitesh Choudhary's](https://www.youtube.com/@chaiaurcode) React.js playlist on Chai aur Code.

This repo follows my earlier JavaScript fundamentals series: [chai-aur-code-js](https://github.com/zubairdev01/chai-aur-code-js).

## 📚 What's Covered

- React fundamentals: JSX, components, props, state
- Hooks: useState, useEffect, and more as I progress
- Component composition and reusability
- Event handling and conditional rendering
- Mini projects to reinforce each concept

## 🗂️ Structure

Each folder represents a topic or project, containing the source code and notes.
